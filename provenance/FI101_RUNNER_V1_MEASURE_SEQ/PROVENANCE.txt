CHANGES
  GET_RESULT in measure-v2: 12-byte form ONLY (base,len,run_sequence).
    8-byte request -> ERR_LENGTH 0x0003.
    Gate (all required): requested_sequence == last_completed_sequence,
    last_run_completed, run_rc == 0, valid_flags mask 0x0F, output_crc != poison_crc.
    Any failure -> ERR_RESULT_NOT_VALID 0x000B, no payload, region never read.
    New last_completed_sequence/last_run_completed are written together only at
    the END of handle_run (the old last_run_sequence was stamped at the top and
    would have matched a run that never finished).
  RUN_VALID_FULL_OUTPUT_EXPECTED_CRC_MATCH (0x10, renamed): reported, NOT required.
    It is a CRC over all 3984 B of .sec_noinit. The golden judgement is the HOST
    comparing GET_RESULT(0x90020cc0, 0x100) == 0x27084C4C -- 256 B, different
    evidence. Never use this flag for that judgement.
  CMD_TEST_SKIP_NEXT_NPU = 0x7E, only under -DRUNNER_TEST_ONLY_HOOKS
    (make TEST_HOOKS=1). 0x7E is the highest usable id: ACK is cmd|0x80 so ids
    must be <= 0x7F, and 0x7F|0x80 == 0xFF == NACK.
