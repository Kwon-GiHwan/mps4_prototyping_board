비율은 반드시 분모와 계산식을 명시한다.

그룹별 NPU_ACTIVE 중앙값의 합이 직렬 전체 NPU_ACTIVE 중앙값과 정확히 같아야 한다고 가정하지 않는다. 반복 RUN의 변동, 측정창 및 경계 비용을 구분한다.

원본과 직렬 실행시간의 차이를 순수한 Kernel overlap 이득으로 해석하지 않는다.

12. Research Direction & Guardrails

본 연구의 장기 목표는 Ethos-U85 Hardware–Compiler Performance Analysis다.

다음 네 축을 균형 있게 유지한다.

Compute / Unit

MAC·DPU·AO·WD, PartKernel·Depthwise·FC, Tensor shape와 컴파일 Mapping의 관계.

Memory / Pipeline / AXI

입력·가중치·출력 데이터 공급, 재사용, 요청·Burst·포트, 실행 중첩과 NPU_ACTIVE의 관계.

Vela Compiler Fidelity

Compute/SRAM/DRAM 비용 모델의 정확성, 과대·과소예측, 성능 변화의 방향과 크기.

End-to-end Model Explainability

7개 MLEK 모델의 실제 실행시간과 효율 차이를 설명하는 능력.

이번 Stage 6F-0은 X3를 확장하는 단계가 아니다.

이미 확보한 그룹 귀속 결과와 연산 Characterization을 전체 모델 및 Vela Fidelity 관점에서 재평가하는 단계다.

다음 원칙을 유지한다.

H1-UC, SRAM 배치, PMU_MASK 또는 AD 잔차 한 가지에 연구를 집중하지 않는다.

이미 검증한 결과를 반복 측정하지 않는다.

예측 가능한 성능 변화만 확인하는 실험을 우선하지 않는다.

새로운 하드웨어 처리 특성과 Vela 모델의 불일치를 규명하는 실험은 계속한다.

검증된 결과, 사후 관측, 외삽 가설을 구분한다.

실제 모델의 실행시간 설명력 개선 여부를 지속적으로 평가한다.

각 실험의 종료 기준과 전체 연구로 복귀하는 경로를 명시한다.

한 가지 현상의 세부 분석 때문에 다른 연구 축을 장기간 중단하지 않는다.

Stage 6F-0은 연구의 종결이 아니라, 다음 실험의 연구적 가치를 판단하기 위한 통합 분석 단계다.
